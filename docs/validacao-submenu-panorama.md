# Validação visual — submenu de Panorama

Em desktop, o item **PANORAMA** permanece visível no cabeçalho, com indicador de expansão para revelar as quatro visualizações internas.

Em celular, o cabeçalho mantém o botão de menu e a marca sem sobreposição do conteúdo. As quatro visualizações ficam disponíveis ao expandir **Panorama** dentro do painel móvel branco.
