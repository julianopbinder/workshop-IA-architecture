# Matriz de inclusão do texto fornecido

| Texto fornecido | Seção na nova página |
|---|---|
| Habilidade para agente, fluxo ou padrão obrigatório | Abertura: “O que é uma Skill” |
| Receita com ingredientes e passo a passo | Metáfora central da abertura |
| Skills de referência e de tarefa | Comparação dos dois tipos |
| Troubleshooting, pipeline, PRD, code review e Kubernetes | Exemplos e seção “Quando usar” |
| Diretório, metadados, instruções e referências | Seção “Estrutura” |
| `SKILL.md` obrigatório em maiúsculas | Estrutura e print do usuário |
| Templates de documentos, Dockerfile e Kubernetes | Bloco “Assets e templates” |
| Fluxo geral em Markdown e arquivos detalhados | Bloco “Quando o processo é grande” |
| Scripts que executam em vez de recriar | Bloco “Scripts” |
| Frontmatter com nome e descrição | Seção “Carregamento progressivo” |
| Acionamento automático ou pelo nome | Seção “Carregamento progressivo” |
| Carregamento completo apenas quando necessário | Print de carregamento e texto explicativo |
| Compartilhamento da mesma Skill entre time, projeto e agente | Fecho “Quando usar” |

## Exemplo adicional solicitado

O tutorial Java mostrará uma Skill de referência chamada `java-api-review`, contendo convenções Java, exigência de teste JUnit 5, regra de segurança de logs e um roteiro de revisão. O fluxo terá: instalar/entrar no Copilot; registrar a Skill no repositório; selecionar um método de validação de pedido; pedir explicação e teste; revisar e executar o resultado.
