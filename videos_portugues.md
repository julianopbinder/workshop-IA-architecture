# Vídeos em português — Skills, MCPs, subagentes e RAG

## Links selecionados

1. **Skills, MCPs e subagentes: quando usar cada um**
   - https://www.youtube.com/watch?v=LFq8gBbS8DQ
   - É o vídeo já enviado pelo usuário. É em português e compara os três conceitos, mas pode ser técnico demais como primeiro contato.

2. **RAG: Everything you NEED TO KNOW to build specialized AIs**
   - https://www.youtube.com/watch?v=s5gv0bdALFA
   - A descrição aparece em português e informa que explica RAG como tecnologia para criar IAs especializadas com fontes de informação.

3. **MCP explicado: O novo padrão obrigatório para apps com IA**
   - https://www.youtube.com/watch?v=DYzJjIjdPLc
   - Título e descrição em português; apresenta MCP como um padrão para aplicações de IA. A confirmação direta da página não foi possível porque o YouTube mostrou verificação automática no navegador.

4. **SubAgentes: A Lógica do Claude Code para Construir Seu Primeiro Produto de IA**
   - https://www.youtube.com/watch?v=4Vam2NJLFrw
   - Conteúdo em português sobre o conceito de subagentes. Deve ser visto por último, pois pressupõe mais familiaridade com agentes de IA.

## Nota de curadoria

Não foi encontrado um único vídeo em português, claramente não técnico, que explique bem os quatro conceitos juntos. Para um iniciante, a sequência menos confusa é: primeiro RAG, depois MCP, depois Skills e por último subagentes. A descrição do RAG pode ser reforçada pela página da IBM em português:

- https://www.ibm.com/br-pt/think/topics/retrieval-augmented-generation
