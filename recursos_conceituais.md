# Trilha conceitual — sem Copilot nem IntelliJ

1. **AI for Everyone — DeepLearning.AI**. Curso iniciante, não técnico, com aproximadamente 6h54min, sem pré-requisito. Apresenta termos de IA, limites e usos na empresa. É a base recomendada antes dos temas de agentes.
   - https://www.deeplearning.ai/courses/ai-for-everyone/

2. **Agent Skills with Anthropic — DeepLearning.AI**. Curso iniciante de aproximadamente 2h19min. A primeira metade explica o que são Skills, por que são usadas e inclui uma aula específica que compara Skills, ferramentas, MCPs e subagentes. Para este momento, assistir apenas introdução, “Why Use Skills” e “Skills vs Tools, MCP, and Subagents”; ignorar a parte de criação por código.
   - https://www.deeplearning.ai/courses/agent-skills-with-anthropic/

3. **Introduction to Model Context Protocol — Anthropic Academy**. Curso gratuito sobre o conceito e arquitetura de MCP. Ele exige Python, JSON e HTTP para fazer os exercícios, portanto deve ser consultado somente após os dois primeiros, para entender a ideia geral.
   - https://anthropic.skilljar.com/introduction-to-model-context-protocol

4. **Introduction to Subagents — Anthropic Academy**. Curso gratuito que explica delegação de tarefas, contextos isolados e quando subagentes valem a pena. É recomendado por último.
   - https://anthropic.skilljar.com/introduction-to-subagents

5. **MCP for Beginners — Microsoft**. Currículo aberto com explicações e exemplos. É complementar e técnico; deve ser usado apenas quando a pessoa quiser avançar da teoria para código.
   - https://github.com/microsoft/mcp-for-beginners
