# Estrutura do guia de Skills

## Objetivo da página

Explicar apenas **Skills** para uma pessoa que nunca usou IA para programação, sem introduzir MCPs, RAG ou subagentes.

## Navegação superior

| Menu | Pergunta que responde |
|---|---|
| O que é | “O que é uma Skill em uma frase?” |
| Onde usar | “Em quais situações ela me ajuda?” |
| Exemplo | “Como uma Skill muda uma resposta da IA?” |
| No IntelliJ | “Qual é o passo a passo na ferramenta?” |

## Mensagem central

> Uma Skill é uma instrução reutilizável. Ela funciona como o manual de trabalho que orienta a IA a repetir um tipo de tarefa do jeito que o seu time espera.

## Regra de apresentação

Cadastrar regras é diferente de confiar cegamente na IA. A Skill dá direção; a pessoa continua responsável por entender, revisar e testar o que foi sugerido.

## Tutorial IntelliJ

O tutorial terá três telas grandes: instalar/entrar no Copilot, criar o arquivo de instruções do repositório e usar uma regra durante uma sugestão Java. Cada tela terá apenas uma ação principal e uma legenda curta.
