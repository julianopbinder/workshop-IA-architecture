# Recursos de estudo selecionados

1. **Microsoft Learn — Introduction to GitHub Copilot**. Módulo oficial para iniciantes, com sete unidades sobre sugestões, chat, configuração e solução de problemas. É a melhor porta de entrada para quem ainda não usa Copilot.
   - https://learn.microsoft.com/en-us/training/modules/introduction-to-github-copilot/

2. **GitHub Copilot Tutorials**. Coleção oficial de tutoriais práticos, incluindo personalizações, instruções, skills, agentes e MCP no Copilot CLI. Deve ser usada depois do módulo introdutório.
   - https://docs.github.com/copilot/tutorials

3. **GitHub Copilot CLI for Beginners**. Curso prático mantido pelo GitHub em repositório, para usar Copilot para codar, testar e depurar. É complementar e usa terminal, portanto não é o primeiro curso recomendado para quem só usa IntelliJ.
   - https://github.com/github/copilot-cli-for-beginners

4. **Anthropic Academy — Introduction to Model Context Protocol**. Curso gratuito, voltado a desenvolvedores com noções de Python, JSON e HTTP; explica ferramentas, recursos e prompts de MCP. Deve ficar para a terceira etapa, não para o começo.
   - https://anthropic.skilljar.com/introduction-to-model-context-protocol

5. **Microsoft — MCP for Beginners**. Currículo aberto com exemplos de código em várias linguagens, inclusive Java. Serve como alternativa prática depois que os conceitos básicos de MCP forem entendidos.
   - https://github.com/microsoft/mcp-for-beginners

6. **Anthropic Academy — Introduction to Subagents**. Curso gratuito sobre delegar tarefas a assistentes isolados, manter contexto limpo e decidir quando subagentes fazem sentido. Recomendado somente depois de Copilot e instruções básicas.
   - https://anthropic.skilljar.com/introduction-to-subagents
